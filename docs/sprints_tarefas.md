# Sprints e Tarefas

## Sprint 1 - Base do Jogo

- Estruturar cartas, baralho e avaliacao de maos.
- Implementar fluxo inicial de run.
- Criar persistencia simples de historico.
- Separar arquivos principais em modulos `.c` e `.h`.

## Sprint 2 - Progressao e Conteudo

- Adicionar perfis de jogador.
- Adicionar categorias de perguntas e quiz.
- Implementar ranking por modalidade.
- Implementar colecao, coringas, tarots, cupons e bosses.

## Sprint 3 - Interface e Entrega

- Criar interface grafica com raylib.
- Ajustar execucao em notebooks com resolucao menor.
- Adicionar scripts `.bat` para execucao.
- Atualizar README e artefatos de entrega.
- Gerar massa de historico com 100 partidas para testes.

## Responsabilidades

- Logica de cartas: avaliacao de combinacoes, pontuacao e baralho.
- Quiz: banco de perguntas, dificuldade e recompensas.
- Interface: telas de menu, run, ranking, historico e colecao.
- Documentacao: README, user stories, plano de testes e evidencias.
