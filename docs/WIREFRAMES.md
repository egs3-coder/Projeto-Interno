# Wireframes e Mockups

As capturas enviadas como referencia foram usadas para orientar:

- Tela final com resumo e personagem provocador.
- Aba de informacoes da tentativa com guias.
- Painel de blinds por aposta.
- Visualizacao do baralho restante.
- Lista de maos de poker com nivel, base e quantidade jogada.

Os elementos foram recriados com `raylib` para manter o executavel leve e compilavel pelo comando principal do projeto.
