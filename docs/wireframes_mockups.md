# Wireframes e Mockups

## Menu Principal

```text
+--------------------------------------------------------------+
| Perfil do Jogador                  | Menu da Run             |
| Nome                               | Jogar / Ranking         |
| Categorias                         | Sessoes / Colecao       |
| Salvar / Desvincular               | Feedback do sistema     |
+--------------------------------------------------------------+
```

## Tela de Run

```text
+--------------------------------------------------------------+
| Jogador | Modalidade | Aposta | Pontos | Moedas | Maos        |
| Feedback                                                     |
| Area de cartas, jokers, tarots e informacoes                 |
| Cartas da mao                         Baralho restante       |
| Jogar | Descartar | Limpar | Informacoes da Tentativa       |
+--------------------------------------------------------------+
```

## Informacoes da Tentativa

```text
+--------------------------------------------------------------+
| Maos de Poker | Blinds | Quiz                                |
| Lista de maos: nivel, fichas, mult fixo e vezes jogadas      |
| Tooltip: explicacao da mao selecionada                       |
| Historico de perguntas: contexto, aposta, status e dicas     |
+--------------------------------------------------------------+
```

## Historico e Ranking

```text
+--------------------------------------------------------------+
| Filtro por modalidade / jogador                              |
| Linhas com timestamp, pontuacao, fases, moedas e resultado   |
+--------------------------------------------------------------+
```

## Referencias Visuais

As capturas de tela anexadas ao desenvolvimento foram usadas como referencia para:

- resumo de fim de jogo;
- tabela de maos de poker;
- informacoes da tentativa;
- tabela de metas por aposta;
- pre-visualizacao do baralho restante.
