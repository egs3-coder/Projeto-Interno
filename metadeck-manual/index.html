01 — Funcionamento

Como o jogo começa

No início da partida, o jogador recebe uma mão de cartas. Ele deve escolher quais cartas jogar para fazer pontos. Também é possível descartar cartas para tentar melhorar a mão, mas existe um limite de jogadas e descartes.

“Escolha suas cartas e tente alcançar a pontuação necessária para vencer a fase.”

Fases

Alcance a meta de pontuação para avançar. Se não atingir a meta, a run termina.

Perguntas

Responda corretamente para ganhar moedas e fortalecer sua partida.

Moedas

Use suas moedas com cuidado. Elas podem ser decisivas nas próximas fases.

02 — Estratégia

Sistemas principais

Loja

Compre melhorias ou guarde suas moedas para a próxima oportunidade.

Pacotes

Abra pacotes e escolha cartas para fortalecer sua estratégia.

Coringas

Equipe coringas para criar combinações mais fortes.

Tarot

Use cartas de Tarot no momento certo para virar o jogo.

Cupons

Cupons dão vantagens contínuas durante a partida.

03 — Desafio especial

Boss encontrado!

Em algumas fases, o jogador enfrenta um Boss. Essa fase é mais difícil, exige uma pontuação maior e pode trazer perguntas mais complicadas ou penalidades.

“Prepare sua melhor estratégia. O Boss é mais difícil que uma fase comum.”
